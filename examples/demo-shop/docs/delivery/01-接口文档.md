- 认证方式：【待确认：代码中未发现认证过滤器、拦截器或 Spring Security 配置。若由网关统一鉴权，请补充请求头约定】

## 2. 用户管理

### 2.1 新增用户

| 项目 | 内容 |
|---|---|
| 接口地址 | `POST /api/v1/users` |
| 描述 | 新增用户。用户名全局唯一，重复返回 1001 |

**请求体**（`application/json`）

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|---|---|---|---|---|
| username | String | 是 | 不能为空（提示“用户名不能为空”），长度 4–32 | 用户名 |
| password | String | 是 | 不能为空，长度 8–64 | 密码 |
| mobile | String | 否 | 正则 `^1\d{10}$`（提示“手机号格式不正确”） | 手机号 |

**请求示例**

```json
{
  "username": "zhangsan",
  "password": "Example@123",
  "mobile": "13800000000"
}
```

**响应参数**

| 字段 | 类型 | 说明 |
|---|---|---|
| data | Long | 新用户 ID |

**响应示例**

```json
{ "code": 0, "msg": "success", "data": 1 }
```

## 3. 订单管理

### 3.1 创建订单

| 项目 | 内容 |
|---|---|
| 接口地址 | `POST /api/v1/orders` |
| 描述 | 创建订单。库存不足时返回 2001 |

**请求头**

| 参数名 | 类型 | 必填 | 说明 |
|---|---|---|---|
| X-User-Id | Long | 是 | 下单用户 ID，见 1.1 |

**请求体**（`application/json`）

| 字段 | 类型 | 必填 | 校验规则 | 说明 |
|---|---|---|---|---|
| addressId | Long | 是 | 不能为空 | 收货地址ID |
| items | Array<Object> | 是 | 不能为空 | 商品明细 |
| └─ skuId | Long | 是 | 不能为空 | 【待确认：代码中无说明，按 SKU ID 理解】 |
| └─ quantity | Integer | 否 | 取值 1–99 | 购买数量【待确认：代码中无说明】 |
| remark | String | 否 | 最长 200 | 买家备注 |

> `items` 内的元素是否触发校验：`items` 上标注了 `@Valid`，所以元素上的 `@NotNull`/`@Min`/`@Max` 会生效。

**请求示例**

```json
{
  "addressId": 1001,
  "items": [ { "skuId": 2001, "quantity": 2 } ],
  "remark": "请尽快发货"
}
```

**响应参数**（data）

| 字段 | 类型 | 说明 |
|---|---|---|
| orderNo | String | 订单号 |
| amount | BigDecimal | 订单金额(元) |
| status | String（枚举） | 订单状态，见 1.4 |

**响应示例**

```json
{ "code": 0, "msg": "success", "data": { "orderNo": "202610310001", "amount": 199.00, "status": "WAIT_PAY" } }
```
