# demo-shop 部署运维手册

| 项目 | 内容 |
|---|---|
| 版本 | 1.3.0 |
| 产物 | `demo-shop-1.3.0.jar` |
| 更新日期 | 2026-10-31 |

## 1. 系统概述

demo-shop 是商城后台服务，提供用户管理、订单管理接口和微信支付回调。服务默认监听 `8080` 端口，上下文路径为 `/shop`。运行时依赖 MySQL、Redis 和外部物流服务。

## 2. 环境要求

| 组件 | 版本要求 | 用途 | 依据 |
|---|---|---|---|
| JDK | 1.8（Docker 镜像 `eclipse-temurin:8-jre`） | 运行环境 | `pom.xml` `java.version`，`Dockerfile` |
| MySQL | 【待确认】 | 业务数据 | `mysql-connector-java` |
| Redis | 【待确认】 | 缓存 | `spring-boot-starter-data-redis` |
| Maven | 3.x | 构建 | `pom.xml`，Spring Boot 2.7.18 |

服务器配置：`Dockerfile` 中 JVM 参数为 `-Xms512m -Xmx1g`，建议服务器内存不低于 2 GB（建议值）。

## 3. 配置说明

### 3.1 配置文件与环境

| 文件 | 环境 | 说明 |
|---|---|---|
| `src/main/resources/application.yml` | 公共 | 端口、上下文路径、日志、mybatis-plus、actuator；默认激活 `dev` |
| `src/main/resources/application-prod.yml` | 生产 | 数据库、Redis、物流服务、微信支付 |

激活生产环境：启动参数加 `--spring.profiles.active=prod`。`Dockerfile` 已内置该参数。

> 代码中没有 `application-dev.yml`，但默认激活的是 `dev`。不带 profile 参数启动时将缺少数据库等配置。【待确认：开发环境配置由谁提供】

### 3.2 关键配置项

| 配置项 | 说明 | 示例/默认值 | 是否必须修改 |
|---|---|---|---|
| server.port | 服务端口 | 8080 | 按需 |
| server.servlet.context-path | 上下文路径 | /shop | 否 |
| spring.datasource.url | 数据库连接 | `jdbc:mysql://<数据库地址>:3306/shop?useSSL=false&serverTimezone=Asia/Shanghai` | 是 |
| spring.datasource.username | 数据库用户 | `<由运维提供>` | 是 |
| spring.datasource.password | 数据库密码 | `******` | 是，由运维提供 |
| spring.redis.host / port | Redis 地址 | `<Redis 地址>` / 6379 | 是 |
| spring.redis.password | Redis 密码 | `******` | 是，由运维提供 |
| logistics.base-url | 物流服务地址 | `<由物流服务方提供>` | 是 |
| wx.pay.mch-id | 微信支付商户号 | `<由客户提供>` | 是 |
| wx.pay.api-v3-key | 微信支付 APIv3 密钥 | `******` | 是，由客户提供 |
| logging.file.path | 日志目录 | /var/log/demo-shop | 按需 |

> 当前 `application-prod.yml` 中的密码和密钥是明文写入代码仓库的。建议上线前改为环境变量或配置中心注入，例如 `password: ${DB_PASSWORD}`。

## 4. 部署步骤

### 4.1 初始化数据库

1. 创建数据库：`CREATE DATABASE shop DEFAULT CHARACTER SET utf8mb4;`
2. 执行 `src/main/resources/db/schema.sql`

项目未使用 Flyway/Liquibase，所以首次部署和升级时都需要手工执行 SQL。

### 4.2 构建

```bash
mvn clean package -DskipTests
```

产物：`target/demo-shop-1.3.0.jar`

> `pom.xml` 定义了 Maven profile `dev`、`prod`，但它们没有内容，打包时无需 `-P` 参数。运行环境通过 Spring profile 区分。

### 4.3 启动

**方式一：Docker**

```bash
docker build -t demo-shop:1.3.0 .
docker run -d --name demo-shop -p 8080:8080 \
  -v /var/log/demo-shop:/var/log/demo-shop \
  demo-shop:1.3.0
```

**方式二：直接运行**

```bash
nohup java -Xms512m -Xmx1g -jar demo-shop-1.3.0.jar --spring.profiles.active=prod > /dev/null 2>&1 &
```

### 4.4 验证

```bash
curl http://localhost:8080/shop/actuator/health
# 期望返回 {"status":"UP"}
```

也可以调用 `GET /shop/callback/ping`，期望返回 `pong`。

## 5. 运维

- 日志位置：`/var/log/demo-shop`（`logging.file.path`），默认文件名 `spring.log`
- 停止：Docker 方式执行 `docker stop demo-shop`；直接运行时执行 `kill <pid>`（Spring Boot 会优雅关闭）
- 监控：actuator 仅暴露 `health`、`info` 两个端点
- 备份建议：每日备份 `shop` 库（建议值）

## 6. 外部系统对接

| 系统 | 配置项 | 网络要求 |
|---|---|---|
| 物流服务 | `logistics.base-url` | 服务器需能访问该地址（出站 HTTPS） |
| 微信支付 | `wx.pay.*` | 微信需能从公网访问 `POST /shop/callback/wxpay`，需在微信商户平台配置回调地址 |

## 7. 常见问题

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 启动报数据源配置错误 | 未指定 `prod` profile，默认 `dev` 缺配置 | 加 `--spring.profiles.active=prod` |
| 时间相差 8 小时 | 数据库或容器时区不一致 | 连接串已设 `serverTimezone=Asia/Shanghai`；容器加 `-e TZ=Asia/Shanghai` |
| 接口 404 | 漏了上下文路径 | 所有地址前加 `/shop` |
| 收不到支付回调 | 回调地址未在公网开放 | 检查网关/防火墙对 `/shop/callback/wxpay` 的放行 |
