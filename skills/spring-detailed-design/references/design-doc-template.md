# 详细设计文档模板

Keep the numbering scheme and id formats exactly: `design_check.py` parses them.

- Requirement items: `R-01`, defined as the **first cell** of a row in the 需求清单 table
- Acceptance criteria: `AC-01`, first cell of a row in the 验收标准 table, with the R id(s) in the second cell
- Questions: `Q-01`, first cell of a row in the 待澄清问题 table
- Design decisions: `D-01`, first cell of a row in the 设计决策 table
- APIs: `` `METHOD /path` ``
- Table design headings: `` #### `table_name` 说明（新增|修改） ``

Everything else is guidance. Drop a subsection that truly does not apply, and write "无" rather than leaving an empty heading where the reader would expect content (e.g. 权限).
